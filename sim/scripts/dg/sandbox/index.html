ADER-DG Order-3 Predictor — WebGL2 Sandbox

Full order-3 predictor: Forward-Euler initialisation at both Gauss–Legendre nodes c1, c2, followed by one Picard refinement sweep. Four shader passes total (no MRT yet). Test PDE: linear advection ut = −ux. Each pass is run on the GPU; an identical computation is performed in JavaScript using the same LGL differentiation matrix; the two are compared pointwise.

No three.js, no MRT, no boundary lifting. This validates the element-local predictor stage end-to-end against a CPU reference.

Setup

  • Domain: x ∈ [0, 1], periodic.
  • Mesh: 16 elements × 4 LGL nodes per element = 64 texels in x.
  • Element width: 1/16 = 0.0625.
  • Initial state: u(x, 0) = sin(2πx) sampled at LGL node positions.
  • Time step: Δt = 0.001.
  • GL2 nodes: c1 ≈ 0.2113, c2 ≈ 0.7887.
  • Picard weight matrix: (a11, a12; a21, a22) = (1/4, c1−1/4; c2−1/4, 1/4).
  • One Picard sweep → combined order min(k+1, 2p) = min(3, 4) = 3.
